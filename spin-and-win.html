Rules

Event name: Spin & Win

Lucky draw rules:

This is a probabilistic reward event, and times of participation don’t affect the possibility of winning.
Every 10 coins can be exchanged for 1 lucky draw chance.
There is no limit on how many times each user may join the lucky draw per day.

How to get coins:

Each user receives 10 coins when first accessing the lucky draw page each day.
You can complete daily tasks to earn extra coins on the Daily Reward event page.

Prize rules:

One More Chance: An additional draw starts immediately without another coin deduction.
Double Coins Card: After receiving this prize, your coins balance is doubled directly.
